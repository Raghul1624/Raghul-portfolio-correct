# Raghul R — Editorial Java Developer Portfolio

A React portfolio redesigned from the supplied black / champagne editorial portfolio reference.

## Design
- Black editorial background
- Champagne / antique-gold typography and borders
- Oversized PORTFOLIO hero typography
- Magazine-style sections and timeline
- Responsive mobile navigation
- Subtle reveal animations
- No extra UI library required

## Run
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

## Optional profile image
The hero currently uses an abstract portrait placeholder so the site works immediately. If you want a real photo, add `public/profile.jpg` and the portrait section can be switched to use it.
